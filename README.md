# TP04: Infraestructura y Diagnóstico de Red
Repositorio para el Trabajo Práctico 04 - Operaciones 1.

## Estructura
- **/config**: Configuraciones YAML multi-entorno.
- **/scripts**: Herramientas de diagnóstico y validación.
- **/reports**: Reportes de red generados.

## Uso de Scripts
Para diagnóstico: `./scripts/diagnostico-red.sh`
Para validar YAML: `./scripts/verificar-config.sh`
